# Cherry Beauty V3 — versão simplificada

Projeto acadêmico de site profissional e responsivo para a Cherry Beauty.

## Estrutura
- `index.html` — todo o conteúdo e estrutura do site
- `style.css` — design e responsividade
- `script.js` — menu mobile e formulário demonstrativo

## Como visualizar
Basta abrir `index.html` no navegador. Também pode usar a extensão Live Server no VS Code.

## GitHub
Crie um repositório e envie estes quatro arquivos diretamente para a raiz. Não é necessário `npm install`, Maven, Java ou banco de dados.

## Railway
Esta V3 é um site estático. Para publicação, configure o serviço como site estático. Alternativamente, GitHub Pages, Netlify ou Vercel também funcionam bem para esta versão.

## Conteúdo acadêmico incluído
História, missão, visão, valores, público-alvo, serviços, preços, diferencial (Kit de Autocuidado Personalizado), benefícios, estratégia de divulgação, FAQ, contato e redes sociais fictícias.

## Observação
O formulário é demonstrativo e não envia dados para servidor. Os contatos, endereço e URLs sociais são fictícios para fins acadêmicos.
